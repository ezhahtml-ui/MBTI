# MBTI Adaptive — بەڵگەنامەی کۆتایی (قۆناغی ١٠)

> دۆخ: **پێشەکی و کالیبرەنەکراو**. ئەم سیستەمە بۆ خۆناسینە، نەک هەڵسەنگاندنی دەروونناسی. هیچ بانگەشەیەکی Valid/Reliable نەکراوە.

## ١. فایلەکان
| فایل | دۆخ |
|---|---|
| `site/index.html` | **گۆڕدراو** (view ی ئەنجامی پاشەکەوتکراو + پاشەکەوتی Supabase) |
| `site/sw.js` | **گۆڕدراو** (`mbti-v5`، ئینجن + بانک لە SHELL) |
| `site/adaptive-engine.js`، `site/question-bank.v1.json` | نوێ لە قۆناغی ٤/٣ (**ناوی بانک بە خاڵ**) |
| `site/admin.html`، manifest، ئایکۆنەکان | بێ گۆڕان لەم قۆناغە |
| `migrations/` | Migration D (ئەپلایکراو) + ROLLBACK.sql |
| `rollback/` | `index.html` و `sw.js` ی پێش قۆناغی ٩ |

## ٢. معماری
ئەپی PWA ی یەک-فایلی؛ Supabase Auth/Postgres؛ `adaptive-engine.js` ماژولێکی deterministic (بێ DOM، بێ network، بێ Math.random، بێ LLM).

## ٣. Adaptive و Scoring
- ٤ هەڵبژاردە: ٢٠/٥٠/٧٥/١٠٠٪ وەک ordinal؛ ٥٠٪ نیوترال نییە.
- مۆدێل: Bayesian ی کلاسیک (priorSD 0.5، noiseSD 0.7) — **ڕێکخستنی ناوخۆیی پێشەکین، نەک IRT و نەک خەمڵاندراو لە داتا**.
- هەڵبژاردن: warm-up (٣ بۆ هەر تەوەر)، پاشان تەوەری کەمترین `|mu|/sd`، فاکتەری کەمترین پۆشش، ناوەڕۆکی هەر ڕەفتارێک تەنها یەک جار.
- جۆر: پیتی هەر تەوەر = نیشانەی mu؛ تەنیشت (mu=0) ← پیتی دووەم + نادڵنیا.
## ٤. Stopping Rules
تەنها لە checkpointەکان (٢٠…١٢٠)، هەرگیز پێش ٢٠، هەرگیز لە ١٢٠ زیاتر. ڕاگرتن کاتێک هەر ٤ تەوەر `pCorrect ≥ 0.95`، ≥٤ وەڵام، ≥٣ فاکتەر. **سنوور:** بانکی ئێستا (٤٠ ناوەڕۆک × ١ دووبارە) تەنها ٤٠ پرسیار دابین دەکات؛ ١٢٠ پێویستی بە ≈٤٨٠ ناوەڕۆکی جیاواز هەیە (٤٤٠ ماون).
## ٥. Question Bank
٣٠٠٠ ڕیز = ٤٠ ناوەڕۆکی ڕەفتاری × ٧٥ وەشانی ووشەدانان. **٣٠٠٠ Item ی سەربەخۆ نییە.** هەموو `approved/active` بە ڕاگەیاندنی خاوەن؛ difficulty/discrimination بەتاڵ (هیچ بەهایەکی دروستکراو نییە).
## ٦. فاکتەرەکان
٢٠ فاکتەر؛ تەنها کاتێک ≥٣ Item هەبێت پیشان دەدرێن، دەنا «هێشتا نادیار». لە بانکی ئێستادا (دووبارە=١) هەمیشە «نادیار»ن.
## ٧. Supabase و RLS
خشتەکان: `test_sessions`، `test_responses`، `test_results`، `research_consents` (+ `profiles`، `admins`، `push_subscriptions`). RLS لەسەر هەموو؛ بەکارهێنەر تەنها داتای خۆی. Migration D: ٣ فەنکشنی ئامار (`is_admin()` + ئامار تەنها، خانەی <٥ شاراوە، توێژینەوە تەنها بە ڕەزامەندی).
پاشەکەوت: هەر وەڵامێک upsert، ئەنجام insert، session دەبێتە `completed`/`abandoned`. localStorage (`mbti_adp_v1`, `mbti_adp_sid`) سەرچاوەی ڕاستە؛ هەڵەی سێرڤەر بێدەنگ و بێ زیان.
## ٨. Calibration
هیچ پارامەتەرێکی IRT نییە. دوای کۆکردنی داتای ڕەزامەندپێدراو (`calibration_ok`) و شیکردنەوەی زانستی. UI ی ڕەزامەندی **هێشتا نییە**.
## ٩. Admin
`admin.html` بانگی ٣ فەنکشنەکە دەکات. تاقی نەکراوە بە ئەدمینی ڕاستەقینە (`admins` بەتاڵە).
## ١٠. Offline
SW `mbti-v5`: network-first (٤ چرکە) + SHELL ی precache (HTML، ئایکۆن، ئینجن، بانک). تاقی کرا: هەڵگرتنی ئەپ و دەستپێکردنی Adaptive بێ ئینتەرنێت.
## ١١. Deployment
١. هەموو `site/` بنێرە بۆ هۆستەکەت (هەمان فۆڵدەر، **ناوی `question-bank.v1.json` بپارێزە**). ٢. بەکارهێنەرەکان بە خۆکار `mbti-v5` وەردەگرن؛ کاشی کۆن دەسڕدرێتەوە. ٣. لە مۆبایل: تێستێک تەواو بکە و `test_results` ببینە؛ Offline تاقی بکە. ٤. ئەدمینێک زیاد بکە و داشبۆرد بپشکنە.
**Rollback:** `rollback/index.html.stage8` و `rollback/sw.js.stage8` بگەڕێنەوە (ناوی `sw.js` بکە، و cache ی `mbti-v4` دووبارە دروست دەبێتەوە). داتابەیس: `migrations/ROLLBACK.sql` (تەنها ٣ فەنکشنەکە). **هیچ داتایەکی بەکارهێنەر ناسڕدرێتەوە.**
## ١٢. Testing (ئەنجامی ڕاستەقینە)
ئینجن ٢٤/٢٤، بانک ٢٩/٢٩، براوزەر ٢٤/٢٤، پاشەکەوت (mock) ١٩/١٩، تێستی کۆن ٥/٥. تێستەکان پێویستیان بە Playwright و فۆڵدەرێکی خاوەن هەموو فایلەکانی `site/` هەیە؛ مسیرەکانی ناو `stage9_*.js` (`/home/claude/work`) بگۆڕە بۆ مسیری خۆت.
## ١٣. ڕاپۆرتی ئاسایش
- RLS: دروست؛ هیچ Service Role Key لە Frontend نییە (تەنها publishable key).
- ماوە: `admins` بێ policy (INFO)، `pg_net` لە public، ٤ فەنکشنی SECURITY DEFINER (چاوەڕوانکراو، `is_admin()` دەپارێزێت)، Leaked Password Protection ناچالاکە.
- نییە: سڕینەوەی session/ئەنجام لەلایەن بەکارهێنەر؛ UI ی ڕەزامەندی.
## ١٤. سنووردارییە ماوەکان
تاقی نەکراو لە ناوەندی من: Login/Register/Profile/Horoscope/Push و Supabase ی ڕاستەقینە (ئینتەرنێت نەبوو). ئینجن کالیبرە نەکراوە. بانکی ٤٠ ناوەڕۆک. ٣ بەشی کۆتایی ڕاپۆرتی جۆرەکان نووسینی پێشەکین. تێستی HTML/CSS validator ی فەرمی نەکرا (تەنها syntax ی JS + براوزەر).
